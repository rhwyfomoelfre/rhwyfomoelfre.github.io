# Clwb Rhwyfo Moelfre

A Jekyll recreation of the Moelfre Rowing Club website, using the supplied local copy, logo, photographs, charts, animation, and PDF resources.

## Run locally

```sh
bundle install --path vendor/bundle
bundle exec jekyll serve
```

Open `http://localhost:4000/`.

The `join`, `league-race-entry`, and `incident-form` routes contain marked placeholders for future Google Form embeds. The source Drupal export remains in `MoelfreWS/` for reference and is excluded from the generated site.
